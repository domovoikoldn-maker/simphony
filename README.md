# «Симфония» 2.0 — мобильная студия (DAW) для Android

Разработчик и владелец: **domovoi4ik** · domovoikold@gmail.com
Java + классические View (XML), без Kotlin/Compose/NDK и без сторонних библиотек (кроме SDK Яндекса в Gradle-сборке).
minSdk 24 (Android 7), targetSdk 36 (Android 16). Размер APK — ~130 КБ: все инструменты синтезируются кодом.

## Что умеет

| | |
|---|---|
| **Дорожки** | до 8: **аудио** (микрофон) и **инструменты** (ноты). Громкость, панорама, Mute, Solo, порядок, переименование |
| **Инструменты** | пианино, электропиано (FM), синт-лид, пэд, бас, орган, струнные, щипок, колокольчики, ударные (GM-раскладка: бочка 36, малый 38, хэты 42/46, томы, тарелки, ковбелл) |
| **MIDI-клавиши** | экранная клавиатура (мультитач, аккорды, глиссандо, сила нажатия по высоте касания, сдвиг октав) + **внешние USB/Bluetooth MIDI-клавиатуры** (android.media.midi, подключение на лету) |
| **Пиано-ролл** | тап — нота, тап по ноте — удалить, тянуть — сдвиг, за край — длина, щипок — масштаб, линейка — курсор. Сетка 1/4…1/32 или без, «выровнять всё», «удвоить», отмена (30 шагов) |
| **Запись нот** | ● Запись нот поверх песни с метрономом, с квантованием по сетке |
| **Запись голоса** | с позиции курсора, остальные дорожки и метроном звучат (в наушниках), компенсация задержки |
| **Эффекты («плагины»)** | 10 встроенных: эквалайзер (3 полосы), компрессор, реверберация (Freeverb), дилей в темп (пинг-понг), хорус, перегруз, фильтр с «вау», тремоло/автопанорама в темп, лоу-фай (биткраш), стерео-расширение. До 6 на дорожку **и на мастер**, вкл/выкл, порядок, все ручки работают во время игры |
| **Транспорт** | темп 40–240 BPM, размер 2/4…7/4, метроном (сильная доля выше), такт.доля + время |
| **Экспорт** | **WAV** (стерео, 44,1 кГц, 16 бит; то же сведение, что слышно) и **MIDI** (SMF 1: все инструменты, темп, размер — откроется в FL Studio, Ableton, GarageBand, MuseScore) |
| **Реклама** | App Open при холодном старте + Rewarded (экспорт без звуковой метки). Только в Gradle-сборке |

**VST/AU-плагины на Android не существуют** (нет такой системы), поэтому «плагины» — встроенные эффекты Симфонии.

## Как получить APK с рабочей рекламой (без Android Studio) — GitHub Actions

Сервер GitHub сам скачает SDK Яндекса и соберёт APK. Бесплатно.
1. Зарегистрируйтесь на github.com → **New repository** (можно Private) → **uploading an existing file** →
   перетащите ВСЁ содержимое архива проекта (папки `src`, `ads`, `android`, `gradle`, `gradle-app`, `.github`, файлы
   `settings.gradle`, `build.gradle`, `gradle.properties`, `gradlew`…) → Commit. Папку `signing/` НЕ загружайте.
   (Скрытая папка `.github` может не перетащиться — тогда создайте файл `.github/workflows/build.yml`
   через **Add file → Create new file** и вставьте его содержимое.)
2. Вкладка **Actions** → «Сборка APK с рекламой» → **Run workflow**. Через 5–10 минут: открыть запуск →
   **Artifacts → simfoniya-apk** → внутри:
   * `Simfoniya-TEST-ads-debug.apk` — тестовые блоки `demo-appopenad-yandex` / `demo-rewarded-yandex`:
     реклама Яндекса показывается **всегда** (денег не приносит) — проверить, что всё работает;
   * `Simfoniya-REAL-ads-release.apk` — ваши блоки `R-M-20314265-3` / `R-M-20314265-2`;
   * `Simfoniya-release.aab` — для Google Play / RuStore.
3. Чтобы release был подписан ВАШИМ ключом (нужно для магазина и обновлений): **Settings → Secrets and variables →
   Actions → New repository secret**: `SIGNING_KEY_BASE64` = содержимое `symphony-release.jks` в base64
   (на компьютере: `base64 -w0 symphony-release.jks`, на Windows: `certutil -encode`), `KS_PASS` = пароль из
   `signing/README.txt`. Без секретов release подписывается отладочным ключом — ставится на телефон, но не в магазин.
4. APK, подписанные разными ключами, не ставятся друг поверх друга — удалите старую «Симфонию» перед установкой.

**Почему настоящие блоки могут сначала молчать:** Яндекс начинает отдавать рекламу по `R-M-…` после того, как
приложение добавлено в partner.yandex.ru и прошло модерацию (часто — после публикации в магазине). Пока этого нет,
приходит `onAdFailedToLoad` → «Реклама недоступна», и приложение работает дальше. Тестовые `demo-…` блоки работают всегда.

## Демо-реклама (сборка без SDK)

`DEMO_ADS=1 ./build.sh` → `Simfoniya-…-demo-ads.apk`: вместо рекламы Яндекса — полноэкранные окна-заглушки с
надписью «ДЕМО · реклама не настоящая». Видно, где появляется реклама при открытии и за награду; работает вся
логика: пауза звука, награда только после досмотра (10 с), закрыли раньше — без награды, каждая 4-я «не загрузилась»
→ «Реклама недоступна». Денег не приносит; **в магазин не выкладывать**.

## Две сборки

| | Как собрать | Реклама | Разрешения |
|---|---|---|---|
| Без рекламы | `./build.sh` (только Android SDK) | нет; метки в экспорте нет | `RECORD_AUDIO` |
| С рекламой | Android Studio / `./gradlew bundleRelease` | App Open `R-M-20314265-3`, Rewarded `R-M-20314265-2` | `RECORD_AUDIO`, `INTERNET`, `AD_ID` (+ `ACCESS_NETWORK_STATE` от SDK) |

Шаги для Gradle-сборки:
1. Android Studio → **File → Open** → папка проекта. Репозитории `google()` + `mavenCentral()` уже в `settings.gradle`;
   зависимость `com.yandex.android:mobileads:7.18.7` (последняя 7.x, API как в 7.1.0; в 8.x другой API) — в `gradle-app/build.gradle`.
2. Вариант **debug** → Run: стоят тестовые блоки `demo-appopenad-yandex` и `demo-rewarded-yandex`.
3. Release: положите папку `signing/` из архива с ключом в корень, `KS_PASS=<пароль из signing/README.txt>` →
   **Build → Generate Signed App Bundle / APK**. Ключ тот же, что у 1.0 — обновление встанет поверх.
4. Проверьте **Merged Manifest** (вкладка внизу `gradle-app/AndroidManifest.xml`).

## Структура

```
src/com/domovoi4ik/symphony/
  MainActivity        главный экран (вертикальный): транспорт, темп, метроном, мастер, дорожки, экспорт, реклама, меню
  InstrumentActivity  экран инструмента (горизонтальный): пиано-ролл + клавиатура + MIDI-вход + запись нот
  Studio              один проект/движок/звук на всё приложение; сохранение, запись, отмена, аудиофокус
  Output              AudioTrack (стерео, режим низкой задержки) + звуковой поток, блоки по 256 кадров (~6 мс)
  MidiInput           внешние MIDI-клавиатуры (android.media.midi)
  FxEditor            окно эффектов дорожки/мастера
  ui/ TrackView, PianoRollView, PianoKeyboardView
  core/  (чистая Java, проверяется на ПК)
    Project, Track, Note  модель: темп, дорожки, ноты в тиках (480 на четверть)
    Engine                движок: ноты → синтезаторы, WAV → дорожки, эффекты, громкость/панорама, мастер, метроном
    Exporter, MidiFile    экспорт WAV / MIDI
    ProjectIO             project.sym (текст; запись через временный файл)
  dsp/   Effect, FxChain, Biquad + 10 эффектов
  synth/ Synth (16 голосов), Drums
  audio/ Wav, TrackReader, Recorder (AudioRecord), Peaks, Chime
ads/src/…/YandexAds   App Open + Rewarded (только Gradle)
desktop/src/EngineTest  проверки ядра на ПК
```
Без лямбд и анонимных классов — только статические вложенные классы (так собирается и старым D8 в `build.sh`).

## Как устроен звук

* **Один движок для прослушивания и экспорта.** Каждый блок: ноты, попавшие в блок (точность 64 сэмпла ≈ 1,5 мс),
  включают голоса синтезатора; аудиодорожки читаются из WAV блоками по 16 КБ (длинные записи не грузятся в память);
  затем цепочка эффектов дорожки → громкость × панорама → сумма → мастер-эффекты → громкость мастера → мягкий лимитер.
* **Запись голоса — AudioRecord** (сырые сэмплы, сразу WAV, видно уровень, срезается задержка), а не MediaRecorder
  (только AAC/AMR — пришлось бы декодировать, начало «плавает»).
* **Воспроизведение — один AudioTrack**, а не MediaPlayer на каждую дорожку (они стартуют вразнобой).
* **Правки на ходу:** ноты и эффекты меняются без блокировок (массивы заменяются целиком), ручки — в начале блока.
* **Хранение:** проект — текстовый `files/project/project.sym`, записи — WAV рядом. SharedPreferences — только
  настройки (задержка, согласие, «чистые экспорты»). Room не нужен: нет таблиц и запросов.
* **Сохранение экспорта** — системный диалог «Сохранить как»: без `WRITE_EXTERNAL_STORAGE` на любом Android.
* Проект 1.0 (4 дорожки) переносится автоматически при первом запуске 2.0.

## Реклама

* **App Open** — один раз за запуск процесса, только при холодном старте (не при возврате из фона, не при повороте).
  Ждём не больше 5 с; не показываем, если открыт диалог (например, согласие), идёт запись/воспроизведение или экспорт.
  **Главный экран вертикальный** — Яндекс отдаёт App Open только приложениям с вертикальной ориентацией
  (экран пиано-ролла горизонтальный, но App Open там не показывается).
* **Rewarded** — кнопка «▶ Реклама → экспорт без звуковой метки». Награда — **только в `onRewarded()`**.
  Не загрузилась — «Реклама недоступна», награды нет. После ошибки загрузки автоматических повторов нет.
* Перед любым показом звук останавливается (`onAdOpening`).
* Нет SDK / ошибка — приложение работает без рекламы.

## Политика и согласия

* «Конфиденциальность» — внизу главного экрана и в меню ⋮; `Intent.ACTION_VIEW` на
  https://judicious-guide-efe.notion.site/4093c4d19f2e805bbbafe6652db34f51
* Первый запуск Gradle-сборки — окно «Реклама и данные» → `MobileAds.setUserConsent(true/false)` до `initialize`
  (пока не ответили — `false`). Меню ⋮ → «Персональная реклама». `setLocationConsent(false)`.
* Записи, ноты и проекты не покидают телефон — как сказано в политике. MIDI-клавиатуры не требуют разрешений.

## Ошибки

| Ситуация | Поведение |
|---|---|
| Нет разрешения на микрофон | запрос → объяснение → «Открыть настройки». Инструменты, эффекты, экспорт работают |
| Микрофон занят / запись < 0,2 с | сообщение, старая запись цела |
| Нет места при записи/экспорте | записанное сохраняется; недописанный экспорт удаляется |
| Свернули приложение | запись сохраняется, звук останавливается, проект сохраняется |
| Звонок / другой плеер | воспроизведение останавливается (аудиофокус) |
| Повреждён project.sym | открывается то, что читается; если не читается — новый проект, старый файл → project.sym.bad |
| Повреждён WAV дорожки | дорожка пропускается, остальное играет |
| Реклама не загрузилась / не показалась | «Реклама недоступна», без награды; приложение работает |

## Проверка

1. **Ядро на ПК:** `javac -d build/dt $(find src/com/domovoi4ik/symphony/{core,dsp,synth} -name '*.java') src/com/domovoi4ik/symphony/audio/{Wav,TrackReader,Peaks,Chime}.java desktop/src/EngineTest.java && java -cp build/dt EngineTest`
   — 40 проверок: все инструменты звучат и затихают, все ударные GM, все эффекты на крайних значениях без NaN,
   демо-песня 7 дорожек + 13 эффектов → WAV и MIDI, точность записи нот, правка нот на ходу, mute/solo, сохранение проекта.
2. **Инструменты:** ⌨ на дорожке «Пианино» → играйте на клавиатуре; ◀ ▶ — октавы; «Пианино ▾» — другой инструмент.
3. **MIDI-клавиатура:** подключите по USB-OTG — внизу панели появится её имя, клавиши подсветятся.
4. **Запись нот:** ● Запись нот → играйте под метроном → ■ → ноты в пиано-ролле; ↶ — отменить.
5. **Голос:** в наушниках ● на аудиодорожке → поёте под остальные → ■. Не совпадает — ⋮ → «Компенсация задержки».
6. **Эффекты:** FX на дорожке → «+ Эффект» → Реверберация, крутите «Размер» во время ▶.
7. **Экспорт:** «Экспорт WAV» / ⋮ → «Экспорт MIDI» → «Загрузки» → откройте плеером/DAW.
8. **Реклама (debug):** холодный старт → тестовая App Open; кнопка за награду → досмотреть → «в запасе: 1».
   Режим полёта → «Реклама недоступна». Логи: `adb logcat -s SymphonyAds`.
